# プライバシーポリシー / Privacy Policy

FANZA Video Player Wide（以下「本拡張機能」）は、ユーザーのいかなるデータも収集・保存・送信しません。

- 本拡張機能は `https://www.dmm.co.jp/monthly/*/-/detail/*` のページに CSS を注入し、サイドカラムを非表示にするだけです
- 閲覧履歴・個人情報・Cookie 等へのアクセスは行いません
- 外部サーバーとの通信は一切ありません

This extension does not collect, store, or transmit any user data. It only injects CSS into FANZA monthly video detail pages to hide the side column. No access to browsing history, personal information, or cookies. No network communication.

連絡先 / Contact: https://github.com/noricha-vr/fanza-video/issues
